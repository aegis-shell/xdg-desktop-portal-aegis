# Contributor Documentation

- Follow the build and protocol-development commands in the
  [project README](../../README.md), and coordinate wire changes with
  [Cross-Repository Protocol Development](cross-repository-development.md).
- Exercise portal dialogs and pickers with [Portal UI Testing](portal-ui-testing.md).
- Read [Documentation Governance](documentation/index.md) before changing
  documentation.
- Record durable Portal architecture decisions in the
  [ADR index](../adr/index.md).
- Run the [Release Checklist](release-checklist.md) before packaging a
  production build.
